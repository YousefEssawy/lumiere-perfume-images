# lumiere-perfume-images

صور منتجات **Lumière Beauty**. الريبو ده مصدر واحد ومحدد: الصور اللي بيقرا منها استيراد
المتجر. مش مكتبة صور عامة.

## ⚠️ اقرا ده الأول

**الريبو ده مش بيخدم الموقع مباشرة.** ويلت بينزّل كل صورة **مرة واحدة وقت الاستيراد**
وبيستضيفها عنده على `assets.wuiltstore.com` (وبيحوّل جزء منها لـ webp لوحده).

يعني:

- **تعديل صورة هنا مش بيغيّر المتجر.** لازم تعمل استيراد تاني أو تغيّر الصورة من داشبورد
  ويلت بإيدك.
- حجم الملف هنا مالوش تأثير على سرعة الموقع — ويلت بيعيد ضغطه بنفسه.

## نمط التسمية

| الملف | الاستخدام |

| `{CODE}_full.jpg` | **النمط الوحيد المعتمد.** 1200×1200، ده اللي ملف رفع ويلت بيشاور عليه |
